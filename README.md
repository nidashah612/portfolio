# Personal Portfolio II — Nida Shah

CS344: Web Engineering — Lab 3 (HTML Advanced)

A multi-page personal portfolio built with plain HTML and one external stylesheet (`css/style.css`).
Layout is done with `float` and `clear`; no JavaScript, frameworks, or CSS libraries are used.

## Structure
```
portfolio/
├── index.html      Home
├── hobbies.html    Hobbies
├── skills.html     Personal skills
├── gallery.html    Image gallery (5 images)
├── contact.html    Contact details
├── css/style.css   All styling
├── images/         profile.png, img1–img5.jpg
└── README.md
```
